# L'avventura di Tom

Un videogioco platform nato dai disegni di un bambino di 7 anni: nove livelli su una mappa disegnata a mano, stile a matita o a blocchi, caramelle, classifica e partita salvata.

Si gioca dal browser e si installa sul telefono come app (Android: menu del browser → Installa app).

Fatto con l'aiuto di Claude (IA).
